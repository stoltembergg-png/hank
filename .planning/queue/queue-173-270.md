## Contrato da fila

- Esta fatia cobre M10 Workflow Engine, M11 Scheduler, M12 Development Agents, M13 Controlled Autonomous Evolution, M14 MCP/Plugins, M15 Remote Runtime e M16 Production Hardening.
- Os IDs `PR-173`–`PR-251` preservam o inventário da fonte. A Milestone 16, não numerada na fonte, é decomposta sequencialmente em `PR-252`–`PR-270`.
- Categorias válidas: `FOUNDATION`, `DOMAIN`, `INFRA`, `BACKEND`, `FRONTEND`, `SECURITY`, `TESTING`, `DEVOPS`, `DOCUMENTATION`.
- “Arquivos/crates prováveis” são alvos de planejamento, não confirmação de existência. Dependências são contratos/resultados, não apenas arquivos.
- O DAG é fail-closed: falha, ausência, timeout, skip, resultado stale ou evidência de SHA/tree/policy incorreto mantém a próxima PR bloqueada.
- Workflow é DAG persistente; recuperação e idempotência antecedem scheduler; scheduler antecede automations. Repository/worktree/policy antecedem development agents. Proposal, evaluation, regression e rollback antecedem self-rollout. MCP transport e permissions antecedem discovery/UI; plugin lifecycle/isolation antecedem provider/tool plugins; remote auth/protocol/credential isolation antecedem remote tools/UI. Prova de release é vinculada ao artefato, SHA e policy.
